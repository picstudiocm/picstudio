Connexion

Connectez cette page à votre dépôt GitHub une seule fois. La clé reste enregistrée uniquement sur cet appareil.

Comment obtenir ma clé d'accès ? (2 minutes)
  1. Connectez-vous à GitHub, puis ouvrez github.com/settings/personal-access-tokens/new.
  2. Token name : PIC STUDIO site. Expiration : la plus longue proposée (1 an).
  3. Repository access : choisissez Only select repositories, puis sélectionnez le dépôt de votre site.
  4. Permissions → Repository permissions → Contents : choisissez Read and write.
  5. Cliquez Generate token, copiez la clé (elle commence par github_pat_) et collez-la ci-dessous.
Laissez « main » sauf si vous avez choisi un autre nom.
